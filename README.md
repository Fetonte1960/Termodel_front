# Termodel Front

Repository pubblico minimale per il sito e il frontend JavaScript di Termodel.

## Pubblicazione

- ramo: `main`
- cartella GitHub Pages: `/docs`
- indirizzo provvisorio di collaudo: `https://fetonte1960.github.io/Termodel_front/`
- indirizzo definitivo previsto: `https://www.termodel.it/`

Durante il collaudo il dominio personalizzato rimane assegnato al repository
pubblico precedente. Il file `docs/CNAME` verrà aggiunto soltanto durante il
trasferimento finale del dominio.

Questo repository deve contenere esclusivamente materiale destinato alla
pubblicazione nel browser. Core C#, WebService, registri di sviluppo e sorgenti
riservati restano nel repository privato `Termodel_sviluppo`.
